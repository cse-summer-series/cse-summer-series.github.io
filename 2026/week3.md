## 🦾 AI-on Activity — one more shot at last week's debugging

I didn't get many replies for last week's **AI-on** activity (I did for the
code! See Discord for discussion), so I want to re-advertise it — it uses
the same tools as CSE29!

**To try it:**

1. Open the Codespace (free programming environment via GitHub in your
   browser):

   https://codespaces.new/cse-summer-series/summer-lab

2. Open `lastword.c` and follow the numbered steps at the top of the file. If
   you finish `lastword.c` and want more practice, try `tree.c` as well

3. The "AI on" part: Paste commands that don't make sense (or even screenshots)
   into ChatGPT / Claude / Gemini / Copilot's free tier and ask what it does
   *before* you run it, then run it and check whether it told you the truth.
   Being new to a terminal is completely expected for many of you; the
   assistant is there to be your guide. Then reach out to me if you get totally
   stuck (one or two of you did, thank you for reaching out!)

   You can also try opening Copilot (for me, it's open on the right panel and
   says "Chat" at the top when I open the Codespace), and ask it for help doing
   things within the codespace directly – ask it about the files, the README,
   the commands, and more!

4. Ask AI how to use `gdb` to find these bugs – what does it say/what do you
   learn? Can it find both? How does it differ from ASan?


Reply via email or on Discord with any or all of:

- the wrong number you got (and whether it changed between runs),
- the line AddressSanitizer blamed,
- the one-line fix, if you got that far,
- the same thing for `tree.c`,
- how to do it with `gdb`
